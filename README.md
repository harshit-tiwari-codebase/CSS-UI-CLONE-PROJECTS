# 🎨 UI Clones Collection

This repository contains a collection of modern UI clone projects built using HTML, CSS, and JavaScript. These projects are focused on improving frontend development skills by replicating real-world designs.

---

## 📁 Projects Included

* 🎯 **Dribbble UI Clone**
* 🎬 **Netflix UI Clone**
* 👗 **Premier Fashion UI Clone**
* 🧥 **Shop Jacket UI Clone**
* 🎵 **Spotify UI Clone**
* 🖼️ **Image Slider**

---

## 🚀 Purpose of This Repository

* Practice frontend development fundamentals
* Improve UI/UX design understanding
* Build real-world project experience
* Strengthen HTML, CSS, and JavaScript skills

---

## 🛠️ Tech Stack

* HTML5
* CSS3 (Flexbox, Grid, Responsive Design)
* JavaScript (Vanilla JS)

---

## 💻 How to Run the Projects

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   ```

2. Open the folder:

   ```bash
   cd your-repo-name
   ```

3. Open any project folder and run the `index.html` file in your browser.
